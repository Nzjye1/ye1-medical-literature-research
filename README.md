# Ye1 医学文献调研

**围绕医学问题检索、筛选和综合文献，建立可持续使用的本地文献库。**

面向支持 Skill 指引的各类 AI Agent，用自然语言交办任务。

## 能做什么

- 围绕医学问题设计检索，查找相关原始研究、综述、指南和安全性证据。
- 整理题录、筛选记录和文献来源，比较研究设计、结果与不同结论。
- 按研究方向建立本地文献库，保存可获取的全文、笔记和调研报告。
- 对照相关综述、指南和关键原文，检查重要研究与结论。
- 继续更新已有方向，按需要追踪新文献，并可衔接 Zotero。

## 安装到你的 Agent

将下面这段话发给你的 Agent：

> 请从 https://github.com/Nzjye1/ye1-medical-literature-research 获取 Ye1 医学文献调研。读取 `skills/ye1-medical-literature-research/SKILL.md`，按照当前 Agent 支持的方式安装完整 Skill 文件夹并检查所需工具，然后告诉我如何开始使用。

也可以下载 [通用 Skill 包](downloads/ye1-medical-literature-research-skill.zip)，解压后将完整文件夹导入或放入所用 Agent 的技能目录；WorkBuddy 用户可使用 [WorkBuddy 导入包](downloads/ye1-medical-literature-research-workbuddy.zip)。

文献检索与本地文献库需要联网与 Python 3；全文获取和引用管理按所用工具配置。

## 开始使用

你可以从当前最需要的环节开始，把下面适合你的一段话发给 Agent。

### 1. 从一个医学问题开始

> 我想了解某种治疗在特定患者中的疗效和安全性，请帮我检索相关医学文献，梳理主要研究、结论和证据来源。

### 2. 按研究类型或范围检索

> 请围绕这个问题寻找近五年的随机试验和系统综述，整理研究对象、干预、主要结局和文献链接。

### 3. 比较不同研究结果

> 请把这些研究按照人群、研究设计、疗效和不良事件做一个对照，说明哪些结果一致、哪些结论不同。

### 4. 建立本地文献库

> 请为这个研究方向建立本地文献库，保存文献题录、筛选记录、可获取的全文和调研报告，并生成方便查找的目录。

### 5. 在已有主题上继续调研

> 请打开我上次整理的文献库，补充这个方向的新研究，保留已有全文、筛选记录和笔记。

### 6. 追踪新文献

> 请持续追踪这个研究方向，按我指定的频率检索新文献，将结果整理到原有文献库，并在有值得关注的新研究时提醒我。

### 7. 使用 Zotero 管理文献

> 我在使用 Zotero，请帮我检查选定文献与现有文库是否重复，并准备可导入的文献记录。

### 8. 回查关键证据

> 请用相关指南或综述检查这次调研有没有遗漏重要研究，并回查主要结论对应的原文或摘要。
