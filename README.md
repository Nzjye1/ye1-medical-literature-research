# Ye1 医学文献调研

**围绕医学问题，检索、筛选和综合相关文献。**

- 根据研究问题整理检索思路、相关证据与研究方向。
- 保存本地文献资料，尽力获取可访问的全文，并区分全文与摘要证据。
- 可按需要继续追踪文献，或为论文写作提供相关来源。

试着说：“帮我梳理这个治疗方法的临床研究现状，保存能获取的全文。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-medical-literature-research-skill.zip)，解压后保留完整的 `ye1-medical-literature-research` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-medical-literature-research` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-medical-literature-research/SKILL.md)。
